# CLAUDE.md

Geppetto (working name in code and older docs: Apprentice): experts record hand skills with Rokoko gloves, learners train against them in 3D. See README.md for the overview and RECONCILE.md for how the two halves of the repo fit.

**Handover (Sat 14 Nov):** read `arpan_info.md` first. It lists what is built, the decisions waiting and the open work in priority order. The track is Rokoko's Robot Teleoperation Challenge, so the robot hand must be central. The core already serves Dex3-1 targets on `/ws/robot` (`core/robot.py`, DECISIONS.md D25). The frontend robot twin that renders them is the top open task. Research and schematics: `research/12_robot_teleop.md`.

## Run

- Backend (in `backend/`): `uv sync`, then `uv run uvicorn app.main:app --port 8000 --reload`. Tests: `uv run pytest -q`.
- Frontend (in `frontend/`): `npm install`, `npm run dev` (port 5173), `npm run build`, `npm run lint`, `npm test`, `npm run e2e` (backend up), `node e2e/mock-walk.mjs` and `node e2e/settings-walk.mjs`, `node e2e/shadows-walk.mjs` (no backend; `E2E_PORT` picks the port), `node e2e/learner-real.mjs` (backend with `GLOVE_SOURCE=simulator`, `LLM_PROVIDER=fake`).
- Local runs: `LLM_PROVIDER=fake`. Mock mode: `?mock=1` / `?mock=0` / `VITE_MOCK=1`, automatic when `/api/health` fails. Dev panel `?dev=1` (per tab, sessionStorage; `?dev=0` clears). Routes: `/expert`, `/apprentice`, `/playground`, `/lab`, `/demo` (visitor flow for the demo table). Kiosk: `?kiosk=1` (sessionStorage, `?kiosk=0` clears) or `VITE_KIOSK=1` locks the app to `/demo` and hides the rail, Settings, expert screens and dev panel (`features/shared/kiosk.ts`).
- Core (repo root): `source .venv/bin/activate` (made with `uv venv --python 3.12`, deps in `requirements.txt`), `python -m pytest -q` (core tests only), `python -m core --fake` (no hardware, debug view at `http://localhost:8765/debug`), `python -m core --solver HOST:12277 --rcsp HOST:45451` (real gloves), `python -m tools.ingest_bridge` (feed `backend/`), `python -m tools.make_pose_lessons` (puppets and letters as core lessons). Full commands and the first-glove checklist: `STATUS.md`.
- Python uses uv only. Never write `pip install` or manual venvs.
- Settings: the "Settings" entry in the rail footer (bottom bar on a phone) opens `features/shared/SettingsDialog.tsx`, a modal with the AI Assistant switch, the margin of error, the score view (3D default, or flat chart), "Add a prop" and reduced motion, all in localStorage (`features/shared/settings.ts`, keys `apprentice.margin`, `apprentice.scoreView`, `apprentice.reduceMotion`). The 3D score flips to the flat chart and back on click, tap, Enter or Space.
- AI Assistant switch: "Enable AI Assistant" in Settings (localStorage `apprentice.assistant`, default on; the rail shows "AI Assistant on/off" as plain text) gates every language-model feature. The flag lives in `frontend/src/features/shared/assistant.ts`; `api/client.ts` refuses `/lessons/generate`, `/lessons/generate_from_video`, `/coach/hint`, `/coach/plan` and `/motion/from_text` before any fetch while it is off (the mock router refuses them too). New LLM endpoints must be added to `ASSISTANT_PATHS`.
- Stage preferences (`features/shared/sessionPrefs.ts`): props (racket, keyboard) are off by default everywhere, the Test your skills games included, behind an "Add a prop" switch (the default is set in Settings, localStorage). With props off the stage draws a chalk sketch in their place (`three/sketchProps.tsx`: racket outline in the hand, keys on the bench, a ring for the ball), so every skill plays and scores the same either way; the expert's last hands choice (one hand left or right, or two) is remembered per move for the session (sessionStorage).
- Margin of error: the learner's `margin` (strict, standard, relaxed, just_trying) multiplies the step tolerance and the hint thresholds (`MARGIN_MULTIPLIERS` in `backend/app/constants.py`, mirrored in `frontend/src/api/margin.ts`), on `POST /score`, `POST /coach/hint`, the mock port and the live corrections (`configFromTolerance`). Standard changes nothing. Relaxed and looser stay quiet inside the widened band, and gold stays for standard or strict.

## Hard rules

1. `docs/CONTRACT.md` is the API source of truth for `backend/` and `frontend/`. Any API change updates it, `frontend/src/api/types.ts` and the mock router `frontend/src/mock/router.ts` together. `SPEC.md` and `schema/` govern `core/` and its `/ws`. Both contracts are frozen; the join is `tools/ingest_bridge.py` (RECONCILE.md section 0). One owner per capability: gloves in and the live practice screen are `core/`; lessons, generation and coach text are `backend/`; one displayed score, the core's live score as 0 to 100.
2. `frontend/src/mock/scoring.ts` and `synth.ts` are ports of `backend/app/services/scoring.py` and `motion/synthesiser.py`. Change both sides together and keep `frontend/tests/mock-scoring.test.ts` (pinned values) passing.
3. Never call paid APIs in tests. `backend/tests/conftest.py` blanks the Gemini key. Never print or copy a key from `backend/.env`; name variables only (`backend/.env.example`). Never commit `.env`.
4. No em dashes anywhere (code, docs, commits). Use a hyphen, comma or colon.
5. Design: Renaissance bottega theme. Gold only for mastery. Vermilion only for corrections. Malachite for correct. No status pills, no kicker labels. Text at least 16px, readable from 3 m.
6. User-facing copy says "expert", not "master" (the top rank is "Sealed", and the seal reads "Sealed by {expert name}"). Wire fields such as `master_name` and code paths under `features/master` keep their names. Any language model in the UI is named openly as "the AI Assistant" (the switch reads "Enable AI Assistant"): never "Gemini", "Gemma" or "coach" in user copy (provider names only in the dev panel). The algorithmic scorer and the live finger corrections are not the AI Assistant.
7. Commit only when asked; then push to the branch remote, authored as the user only, no Claude trailers. Ask before force push or push to main.
8. Naming: the product is **Geppetto**. "Apprentice" was the working name. Titles, headings, page `<title>`, package descriptions, prompts and pitch copy say Geppetto. The learner role and rank keep the word "apprentice" (routes `/apprentice`, "I am an apprentice", ranks Apprentice, Journeyman, Sealed), and code paths, localStorage keys and wire fields keep their names (the rename is done, Sat 14 Nov; also the internal `X-Apprentice-Mock` header and the DevPanel "Apprentice guidance default", which is the role). `research/` keeps the old name as history.
9. The root-level `core/`, `schema/`, `tools/`, `tests/`, `lessons/`, `config.toml`, `SPEC.md`, `RECONCILE.md`, `STATUS.md` and `DECISIONS.md` are the teammate's real glove, scoring and ML pipeline (PR #1). Never edit, replace or overwrite them from `frontend/` or `backend/` work, and never add a competing glove or ML path. If a change seems to need them, stop and ask. Exception (the user, 14 Nov): formatting-only changes from ruff (the end-of-turn hook) may be committed anywhere, these folders included, as long as tests still pass; commit them in their own commit, never mixed with real changes.
